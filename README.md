# Vasta

Vasta is a modern, internet-connected messaging application.

## Vision
Build a fast, secure, and simple chat experience with real-time messaging, accounts, media sharing, notifications, and a responsive interface.

## Project status
Initial project setup.

## Planned stack
- Next.js / React
- TypeScript
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
- Vercel

## Development principles
- Security first
- Mobile-first responsive UI
- Real-time data where appropriate
- Free-tier friendly architecture during early development
