# Vasta Product Roadmap

## Vision
Vasta is a modern internet-first messenger focused on speed, privacy, personalization, and useful AI.

## MVP
- Email account creation and login
- User profiles
- Search users by email
- Real-time one-to-one messaging
- Online/offline presence
- Responsive Arabic RTL interface

## V2
- Username system
- Image and file sharing
- Message replies, editing, deletion, reactions
- Typing indicator and read receipts
- Push notifications
- Multi-device sessions

## V3
- Voice and video calls with WebRTC
- Groups and communities
- Channels
- Stories/status
- Disappearing and locked chats
- Advanced privacy controls

## V4
- AI assistant inside chats
- Translation and rewriting
- Conversation summaries
- Spam and abuse protection
- Advanced search
- Themes and per-chat customization

## Product principles
- No secrets committed to GitHub
- Server-side authorization and least-privilege rules
- Mobile-first performance
- Graceful behavior on slow connections
- Features are added only after the core messaging flow is reliable
